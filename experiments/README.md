# 动态 OT 实验：新服务器起点

当前远端仓库原先仅含研究网站。这里从零搭建实验；没有导入旧服务器成果。
旧服务器的 77 个留出时间点和 46.2% 改善未在本工作区恢复或复现。本机已完成基线、固定预算动态 CTD、共享外观优化、离线 split、约简模型一次／两次预设 split 门控及敏感性检查；完整 4DGS 自适应致密化尚未实现。

## 存储与准备

根目录 `/data3/store1/<当前用户名>/`，所有数据、环境、缓存、模型和实验输出必须位于此处。
`source scripts/common.sh` 会加载根目录的 `migration-env.sh`，并把工具 HOME 隔离到数据盘。
不得在 `/home` 安装，不得运行 `conda init`，不得覆盖已有实验。

1. `bash scripts/bootstrap_env.sh`：校验安装包 SHA256，在数据盘安装 Miniforge 与 Python 3.10 / PyTorch 1.13.1 cu117 环境，从 NVIDIA 官方再分发包安装最小 CUDA 编译工具链到 `envs/cuda-11.7.1/`（SHA256 已固定），使用 GCC 11 编译两个 4DGS 扩展。
2. `source scripts/common.sh; source "$RESEARCH_ROOT/miniforge3/etc/profile.d/conda.sh"; conda activate "$GS_ENV"`。
3. `python scripts/preflight.py` 检查存储、仓库、缓存和已有数据；`--require-ready` 同时要求数据与依赖完整。
4. `python scripts/verify_env.py` 做小规模 CUDA KNN 与光栅化前后向验证，不训练。
5. `python scripts/prepare_bouncingballs.py` 从 4DGS README 给定的官方 D-NeRF 链接下载数据，只解压 bouncingballs；在数据目录生成每个文件的 SHA256 清单。已有目录只检查，不覆盖。
6. `python scripts/baseline.py --gpu 0` 只显示完整训练命令。确认 GPU 调度与检查通过后，`--run` 才会启动训练；每次创建新输出目录，并保存日志、运行 manifest 和 pip freeze。

基线使用官方 bouncingballs 配置（coarse 3000 / fine 20000，源代码种子 6666）。源数据和模型目录始终以绝对路径传入。默认 GPU 0 是待调度参数，不代表预留了该卡。

## 实验顺序与判据

- E00：下载官方 D-NeRF bouncingballs，核对 train/val/test 元数据及每张图像；保存来源和哈希清单。
- E01：原始 4DGS 基线；独立输出目录、固定种子、记录 Git SHA、完整命令、环境清单和 cfg_args。
- E02：固定高斯预算的逐帧 GHAP 与共享轨迹约简对比，先比较分布误差、时序残差、PSNR/SSIM/LPIPS 与耗时。
- E03：位置/协方差/速度项消融；训练时间与留出时间分开，不先假定速度项有效。
- E04：跨训练时刻共享 SH/opacity 外观微调；由前面结果决定是否推进。
- E05：离线 CTD split 候选及预算／顺序稳定性验证。
- E06：约简模型训练循环中的单次 split 接受事件及同数量对照；完整 4DGS 训练期自适应 split/merge 仍为研究目标。
- E07：门控价格与试跑长度的单因素敏感性，四个新条件及复用 E06 标准条件。
- E08：相同候选预算下的一次／两次事件调度、实际累计高斯更新与门控对照。
- E09：第二次事件按当前渲染收益、旧渲染收益、固定CTD或随机批次重新选点，同状态同数量对照。
- E10：24个独立单批split与匹配不拆分对照，诊断即时／短期评分对最终收益的预测能力；本地更新。
- E11：冻结模型的监督目标／损失／同时间相机／400与800分辨率口径诊断，零训练更新；本地更新。
- E12：教师目标主对照与一致学生渲染解释组，固定CTD候选、两种数量及三组后续训练顺序；本地更新。
- E13：有界共享位置优化及固定分配CTD联合项，直接逐源代价核验、同数量三组顺序对照；本地更新。
- E14：新增9组均匀L2，核验复用E13的15组对照，比较源质量加权的作用；本地更新。
- E15：拟合集顺序42校准1%／4%偏离预算，锁定λ后执行43／44，报告匹配标记与全部指标；本地更新。
- E16：回到固定10000共享分组，对照平均／矩匹配协方差与相同外观微调；PSNR和时间残差改善、LPIPS恶化，保留取舍不直接集成；本地更新。
- E17／E17b：冻结模型空间LPIPS与教师对齐诊断；像素误差改善和感知误差恶化并存，定位到训练目标与评估目标的取舍；本地更新。

不把训练后固定预算约简称为自适应致密化。暂不进行真实物理守恒的结论推断。

`python scripts/audit_times.py` 单独检查视角划分与时间划分。

## E02：固定预算 CTD 对照（2026-11-03）

完成 5000／10000／20000 三个预算、每个预算全部 150 个时间点的单种子对照。逐帧方法是每个评估时间重新拟合的 oracle；共享方法只用 76 个时间拟合固定分组，再应用于其余 74 个时间。底模见过全部这些时间。使用真实激活后的均值和完整协方差，时间共享 SH/opacity；状态重渲染与原生渲染的最大像素误差为 6.56e-7。
这是 GHAP CTD 核心适配，并非官方完整流程复现。代价为位置平方差加协方差 Frobenius 平方差，不是 KL 或高斯 W2。采用全局分块距离、float64、精确预算空簇修复和直接协方差渲染；原始仓库未修改。共有 50 轮上限，各预算共享拟合及 150/150 个逐帧拟合均收敛。20 轮试跑保留为独立记录。

| 高斯预算 | 逐帧 PSNR | 共享 PSNR | 共享时序残差相对降幅 |
| --- | --- | --- | --- |
| 5000 | 29.012 | 28.763 | 42.5% |
| 10000 | 33.828 | 33.615 | 30.7% |
| 20000 | 39.349 | 39.233 | 21.9% |

PSNR 为原始 20 个测试视图、保存等价 8-bit RGB 的均值；LPIPS 按标准 normalize=True 口径记录在完整报告。时序残差为固定相机 256 分辨率下，约简与完整底模的相邻 RGB 帧差之差的平均绝对值，不是轨迹速度误差，也不是旧实验的 46.2% 指标复现。共享方法在三个预算上残差更低，但 PSNR 和 LPIPS 略差。单场景、单种子，仅支持当前设置下的初步取舍结论。

## E05：离线 CTD split 候选初验（2026-11-04）

在 E04 联合微调后的共享 K10000 表示上，固定新增 256 个高斯。只用 76 个拟合时刻，在每个原父分组内做加权轨迹二分，四种评分共享同一套子分组：五个等时长窗口平均收益的最小值、全拟合时间平均收益、首帧收益、随机抽样。首帧组只消融评分，不是完整的独立逐帧算法。分组身份固定后在全部 150 个时刻应用，仍依赖完整底模轨迹。

五组均从 E04 外观出发，再用相同视图顺序优化 1520 步 SH／opacity；包含不 split 的继续微调对照。分裂子节点继承父 SH，按混合权重比例分配光学厚度；只在重合足迹假设下保持透射率，不保证不同几何下初始图像完全不变。

## E18 后的研究决策：调研想法如何使用（2026-11-10，本地记录）

研究主线仍是 GHAP/CTD 的分布级约简进入动态4DGS后，如何维持跨时间身份，并用有依据的分布收益与渲染收益决定表示容量。当前实验覆盖了其中的基础层，而不是完整方法：E02/E04已得到固定预算的全局共享轨迹分组及外观微调；E05～E09做了教师几何固定条件下的离线子轨迹split提案和有限训练事件；E13～E15检验固定分配CTD位置约束与均匀L2；E16～E18检验代表协方差和外观损失的画质取舍。逐帧对照是GHAP/CTD核心适配，并非完整官方GHAP流程。现有CTD代理使用位置平方差＋协方差Frobenius平方差和归一化源opacity权重，不是Gaussian W₂，也未实现时间上的新输运耦合；opacity不是物理质量。

暂不作为核心结论或默认模块：E15在成功匹配的4%偏离预算下未发现CTD相对普通L2的全面优势；E16矩匹配代表协方差改善PSNR／时间残差但明显损害LPIPS，E18固定感知损失只部分缓解；直接速度差项与强速度权重的旧探索也没有提供稳定画质收益。这些结果不等于否定动态OT构想，只限定了目前可支持的说法。不把不同支持数、训练自由度或实验口径的分数混作方法排名，不用本场景GT继续挑超参数。

下一阶段按证据推进：先锁定固定共享分组与外观基线，在未参与设计的第二场景独立复验质量、时间残差和教师依赖；再做小规模固定分配对跨时间更新分配的同预算、同训练量比较，保留普通L2与简单渲染收益控制；只有分配更新显示可靠收益，才将时间窗口分布收益用于split候选，并用拟合集窗口渲染收益决定接受。之后才研究反复split／merge、随物理时间变化的表示容量、共享SH／opacity与独立压缩运动模型。当前训练期完整4DGS自适应split、独立运动预测和推理加速仍未完成。这是后续实验顺序与检验条件，不是已取得的结果。

## E21：Gaussian W2 几何尺度核对（2026-11-10，本地更新）

E20的旧代理代价把位置差平方（长度²）与协方差矩阵差的Frobenius平方（长度⁴）直接相加，拟合集固定分组中协方差项只占0.0644%。预先固定协议 `gaussian-w2-scale-audit-v1.json`，只读取E19/E20已冻结的源状态、代表状态、分配关系和原始PLY opacity，对**全部101个拟合时刻×3组×24985源高斯**逐对重算。新对照采用两个高斯之间的W2平方几何代价：位置差平方加协方差Bures距离 `Tr(A+B−2(A^(1/2)BA^(1/2))^(1/2))`；两项均为长度²。这里仅评估既有分配的代价，不按W2重新分配、不训练、不访问GT或约简留出时刻。该W2几何对照也不等同于GHAP完整CTD目标。

| 已冻结分配 | 旧Frobenius协方差占比 | Bures协方差占比 | 位置代价相对固定组 | Bures代价相对固定组 | W2总成本相对固定组 |
|---|---:|---:|---:|---:|---:|
| E19固定分组 | 0.0644% | 21.08% | — | — | — |
| E20完整几何窗口 | 0.0908% | 27.75% | −27.09% | +4.86% | −20.35% |
| E20仅位置窗口 | 0.0913% | 27.80% | −27.11% | +5.07% | −20.33% |

表中占比是**所有拟合时刻平均成本的比值**，不是各时刻占比再平均。结论是当前旧代理几乎忽略形状；使用量纲一致的Bures项后，形状贡献变得可观。E20换组虽使位置代价下降，Bures形状代价却上升，说明旧代理的“完整几何收益”主要反映位置聚合。两种窗口法在既有分配上的W2总成本仍比固定组低约20%，但它们从未按W2选择分配，不能据此声称W2驱动会改善画质或CTD/OT已有优势。

独立复核E20的303条拟合时刻位置／旧完整代价，最大差2.11e−13；固定组聚合旧协方差占比也与E20审计一致。Bures矩阵计算采用float64，输入协方差对称化，对数值级负特征值截断到0；原始Bures值最小负数约−4.53e−12，超过0的物理成本不受影响。结果、输入哈希和数值诊断在 `outputs/ot/e21-gaussian-w2-scale-20261110-v1/report.json`，复核在同目录 `audit.json`；入口 `scripts/run_gaussian_w2_scale_audit.py`，状态索引 `e21-status-20261110.json`。没有修改旧实验或提交／推送。

下一步应先固定一个**跨窗口连续性规则**与W2候选分配算法的计算预算，检查它是否在拟合时刻给出与位置规则实质不同、且不增加边界跳变的分配；再在新场景比较同K、同训练量的简单位置控制、W2几何控制及连续性控制。新场景的GT只能在规则冻结和模型训练完成后用于评估。若没有对简单位置法的稳定优势，就不能把该分配规则直接升格为训练期自适应split。

## E22：官方 4DGS 训练期 split 小试（2026-11-10，本地更新）

E06～E15的“split事件”发生于教师几何固定的约简模型，后续只优化外观／局部共享偏移，不是官方4DGS的位置、尺度、旋转、deformation训练。因此本轮预先固定 `official-training-split-pilot-v1.json`，直接在已训练到fine 20000步的官方 `jumpingjacks` 底模上继续训练：从最终PLY和deformation权重恢复24985个高斯，**原始Adam状态未保存**，故三组共同新建优化器并预热128步，再从完全相同的保存状态分支，各继续152步。无split、官方屏幕空间梯度最高的64个可split父高斯、跨101拟合时刻平均的opacity加权Gaussian W2压缩失真最高的64个可split父高斯，采用同一官方 `densify_and_split(N=2)` 操作，后两组各净增64个高斯至25049。两组名单没有交集。后续训练继续使用官方fine渲染、L1／DSSIM／deformation正则与相同相机顺序；所有模型冻结后才读官方20个test视角。跨时间W2名单是**相对E19固定压缩代表的源失真启发式**，不是GHAP CTD拆分收益，也不直接预测GT渲染收益。

| 条件 | 高斯数 | GT PSNR ↑ | GT SSIM ↑ | GT LPIPS ↓ | 相对不split的PSNR |
|---|---:|---:|---:|---:|---:|
| 不split继续训练 | 24985 | 35.228519 | 0.98530520 | 0.01613669 | — |
| 官方梯度top64 split | 25049 | 35.129398 | 0.98515446 | 0.01644285 | −0.09912dB |
| 跨时间W2失真top64 split | 25049 | 35.225887 | 0.98527055 | 0.01618899 | −0.00263dB |

**结论是负结果**：在这个已训练完成的底模上，跨时间W2选点比普通梯度选点少损失约0.0965dB，但两种split的PSNR、SSIM、LPIPS均未超过相同继续训练预算下的不split组。W2组相对不split的PSNR只差0.0026dB，单底模／单顺序／20视角不足以把它解释成优势。这里测试的是训练完成后的小规模继续训练，不能直接推断标准4DGS在早期致密化阶段的效果，也不能把这个W2代理称为OT/CTD动态致密化成功。

运行中两次实现错误被保留并排除：`v1`在共同预热后、任何split前因恢复的deformation模块仍在CPU而退出；`v1b`虽完成，但独立审计发现从PLY恢复时 `spatial_lr_scale=0`，使位置、deformation、grid学习率均为0，因此**不计为本实验结果**。`v1c`恢复deformation至CUDA并将空间学习率尺度设为官方Scene计算的extent（5.9227），每步断言三组学习率均为正；独立审计三组checkpoint的deformation权重均有更新，13个输入哈希不变，三组高斯数量、60条test记录及均值复算通过。有效运行目录 `outputs/ot/e22-official-training-split-20261110-v1c/`，报告 `report.json`、审计 `audit.json`、状态索引 `e22-status-20261110.json`；两个错误目录未覆盖。脚本 `scripts/run_official_training_split_pilot.py`。没有提交／推送。

下一步不应在同一完成场景反复调W2评分。要检验核心假设，应从**原始训练的致密化阶段**保存包含Adam状态的共同检查点，在尚未饱和的训练阶段，按相同新增高斯预算与后续训练量比较官方梯度、明确的跨时间CTD/W2拆分收益和不split；把评分额外计算开销与画质、时间连续性一起报告。E22已证实训练代码路径可跑通，也证实晚期继续训练的这一失真启发式没有胜过不split。

## E22 后的路线修订：教师—独立学生—容量收益（2026-11-11）

上述“直接进入原始4DGS训练阶段”的建议是E22结束时的备选方向。综合E02～E22的证据，当前**优先主线**改为预算受限的动态教师—学生模型：完整4DGS在训练时提供各时刻目标分布与图像，学生以较少的canonical高斯和可训练deformation独立预测整段运动；推理时不得再读取教师逐时刻状态。这样GHAP式约简有明确目标，split也发生在确有表示容量缺口的学生上。原生4DGS从头致密化暂列后续扩展，需另外定义没有教师时的目标分布，不能把“难压缩源高斯”直接当作“应拆分完整模型高斯”。

现有诊断说明为什么必须修订：E20仅位置对照略优于所谓完整几何窗口规则，且窗口边界残差升约2%；E21证明旧代理协方差项只占固定组代价0.0644%，W2/Bures替代项虽有合理尺度，却不是GHAP的CTD，也未证明能改善选点；E22直接在完成模型上按W2压缩失真拆分，未胜过不split。E19的K=9276约简学生仍依赖教师逐时刻几何，PSNR 32.5363dB相对完整教师35.2510dB有明显差距。故当前没有“动态OT自适应致密化已成功”的结论。

接下来的顺序是：① 从现有共享分组初始化**可独立运动**的有限K学生，训练其canonical几何、deformation、SH与opacity，并建立不读教师的渲染路径；② 明确源权重、协方差尺度、时间对应与可复算的教师—学生分布代价，GHAP CTD与Gaussian W2分别标记，不能混称；③ 对同一学生候选split计算拆分前后的窗口分布／拟合视角渲染收益，减去新增容量价格，而不是按源高斯的压缩失真排序；④ 固定高斯预算和训练量，同不split、随机、普通位置／渲染规则比较测试画质、未拟合时间的教师保真、边界闪烁、速度和显存；规则固定后到新场景复验。先完成独立学生，再做split决策；没有独立运动预测就不把oracle聚合的漂亮数字当作可部署动态方法。此节是后续计划，不是新实验结果。
